1. Cài đặt nhanh bằng Docker & GNU Make

Hệ thống được đóng gói hoàn chỉnh thành 4 containers (career_coach_pg, career_coach_ollama, career_coach_backend, career_coach_frontend). Không cần cài đặt Python, Node.js hay PostgreSQL trên máy thật. 

git clone https://github.com/tql-team/ai-career-coach.git
cd ai-career-coach

# Cách 1: Cài đặt tự động qua GNU Make
make install

# Cách 2: Cài đặt trực tiếp qua Docker Compose
docker compose up --build -d

# Kiểm tra log trực tiếp của Model AI (Qwen 3.5:4b)
docker compose logs -f backend
